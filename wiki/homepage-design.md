# 홈페이지 디자인과 참고 사이트

기준일: 2026-10-28. 실제 소유자 사이트의 공개 콘텐츠를 열어 확인했다. 각 사이트의 모바일 동작·시각 효과 전체를 직접 검증한 것은 아니다.

## 사용자 확정

깔끔하고 심플한 분위기, 모바일·웹 반응형, 게임·개발 프로젝트·이력. 승인된 STUDIO 위 / KWONYC 아래 로고 사용.

우선 제안은 **Brittany의 정보 구분 + Maddy의 게임 목록 + 밝은 배경·남색 로고**다. 최종 선택은 미확정이다. 글·이미지·코드를 복제하지 않고 구조를 참고한다.

## 메인 구성 제안

1. 로고·짧은 소개·주요 링크.
2. 대표 게임 하루 스도쿠: 이미지·설명·플레이·개발 기록.
3. 개발 프로젝트: 역할·기술·결과·관련 링크.
4. 소개·이력: 기간·활동·경험.
5. 개발 기록·GitHub 등 외부 링크.

실제 직무·경력·기간·연락처는 아직 받지 않았다. 임의로 채우지 않는다.

## 반응형 검증 목표

- 모바일 360~430px, 태블릿 768px, 데스크톱 1280~1440px에서 확인.
- 좁은 화면 한 열, 넓은 화면 카드 여러 열·적절한 최대 본문 폭.
- 전체를 축소하지 않고 열 수·여백·글자·이미지 크기를 조정.
- 가로 넘침·200% 확대·키보드·터치·모션 감소 설정 점검.
- 위 기준은 목표이며 홈페이지 구현 완료가 아니다.

# 홈페이지 디자인과 레퍼런스

기준일: 2026-10-28.

## 사용자 확정

- 후속 디자인 수정: 흰색·네이비를 기본으로 기존 라벤더·라임·살구색 등 소량의 포인트는 유지한다. 본문 한글은 Pretendard, 영문은 Poppins를 로컬 무료 폰트로 사용하고, make it playful 장식만 기존 세리프 느낌을 유지하는 예외로 확정했다.
- 첫 화면은 WELCOME. STUDIO KWONYC / 생각나는 모든 걸 만들어 보는 작은 공방 / 둘러보기. 소개의 큰 별 장식 대신 승인 로고, 작은 푸터 문구 Creative Idea를 적용한다.
- 스도쿠 소개 이미지는 최근 네이비·화이트 캡처로 교체하고 이미지가 소개 글을 가리지 않게 순서대로 배치한다. 작업 카드의 하단 링크 구분선은 같은 행에서 맞춘다. 세부 내용은 디자인 이후 천천히 수정한다.

- 깔끔하고 심플한 모바일·태블릿·데스크톱 반응형.
- 게임·개발 프로젝트·본인의 이력을 담는다.
- STUDIO 위 / KWONYC 아래의 승인 로고를 사용한다.
- **선택한 레퍼런스:** https://baekseongjun.github.io/ 와 https://studio.design/

기존 Brittany·Maddy·Lee 등의 제안은 탐색 기록이며 현재 기준은 위 두 사이트다.

## 확인과 해석

첫 번째 사이트는 웹 조회 도구에서 접근하지 못했지만 브라우저 접근성 트리로 제목과 섹션을 확인했다. README.md / About.md / Strengths.md / Projects.java / Challenges.java / Skills.yml / Contact.md의 탐색, 소개·프로젝트·문제 해결 중심 구조를 참고한다. 그 사이트 소유자의 경력·작품·사진은 가져오지 않는다.

Studio.Design은 웹 조회와 브라우저 접근성 트리에서 큰 제목·기능 소개·작업 예시·이야기 흐름을 확인했다. 제목과 여백, 작업물을 중심으로 보여주는 방향을 참고한다. Studio.Design 서비스로 호스팅을 옮기는 요청은 아니며 Oracle 운영을 유지한다.

참고 사이트의 소스·이미지·문구를 복제하지 않았다. 브라우저 캡처 API 문제와 이후 URL 판별 실패로 시각 캡처·CSS 상세 실검증은 미완료다. 아래 디자인은 확인한 정보 구조에서 해석한 창작 초안이다.

## 구현한 1차 초안

- 밝은 배경·남색 로고·넓은 여백·큰 한국어 제목.
- 상단 홈/작업/소개/기록 탐색에 README·PROJECTS 등의 보조 표기.
- 히어로의 스도쿠·타이포그래피·개발 기록 카드는 HTML/CSS로 구성.
- 작업 카드: 기존 배포 게임 하루 스도쿠, 현재 만드는 Studio KWONYC 홈페이지.
- 소개 문구와 실제 위키로 이동하는 개발 기록.
- 모바일 한 열·접이식 메뉴, 태블릿/데스크톱 분기, 확대와 모션 감소 고려.

게임 카드는 기존 Pages로 연결하는 제안을 초안에 적용했다. 게임 이전은 미확정이다. 소개·슬로건은 검토할 초안이며 확정 이력으로 기록하지 않는다. 실제 경력·기간·연락처가 아직 없어 가짜 이력 섹션은 넣지 않았다.

## 검증 범위

로컬 브라우저 접근성 트리에서 제목·섹션·링크 표시를 확인했다. 파일·앵커·리소스 참조, JavaScript 문법, 메뉴의 열기/닫기·Escape·메뉴 선택·데스크톱 전환·외부 클릭 검사를 통과했다.

모바일 360~430px, 태블릿 768px, 데스크톱 1280~1440px, 200% 확대의 실제 시각·가로 넘침·터치 검증은 미완료다. 자동 제어가 현재 URL을 충분히 판별하지 못해 중단됐다. 정적 검사를 화면 검증으로 대신하지 않는다.

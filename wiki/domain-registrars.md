## 추천 기준

최신 사용자 선호: 한국에서 운영하므로 국내 이용 환경에 맞는 업체를 선호한다. 이에 따라 한국어 안내·원화 결제 기준으로 **가비아를 추천**한다. 가비아 선택 확정·가입·구매 완료는 아직 사용자 확인 전이다. 이전 Porkbun 추천은 현재 사용자 선호에 따른 우선 추천에서 제외한다.

진행: 가비아 접속 → 도메인 검색에 studiokwonyc.com 입력 → 등록 가능 여부·1년 결제 금액·갱신 가격 확인 → 도메인만 선택 → 소유자 정보 정확히 입력 → 사용자 직접 결제 → 등록자 이메일 인증. 웹호스팅·유료 SSL은 이번 구성에 필수 구매 항목이 아니다. 이메일 등 별도 서비스가 필요하면 따로 결정한다.

- 비교한 업체 중 장기 단가 우선: Cloudflare Registrar. Cloudflare DNS를 사용하며 A 레코드로 Oracle VM에 연결한다. 웹 호스팅을 Cloudflare로 옮기는 제안이 아니다.
- DNS 선택 유연성과 해외 구매 가능: Porkbun. 비교된 연간 차이는 Cloudflare 대비 USD 0.62로 작다.
- 한국어 지원·원화 결제 우선: 가비아. 정가와 이벤트 결제가를 구분하고 11월 인상 공지를 반영한다.

모든 경우 Oracle VM은 그대로 사용한다. 웹호스팅·유료 SSL·메일 부가상품을 이번 도메인 구매에 필수로 보지 않는다. 현재 Caddy로 HTTPS 발급·갱신하는 계획을 유지한다.

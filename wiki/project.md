# 프로젝트 현황

기준일: 2026-10-28. 과거 과정은 [작업 일지](work-log.md)에서 확인한다.

최신: 사용자가 백성준 포트폴리오·Studio.Design 두 레퍼런스를 확정했다. site/에 정적 반응형 1차 초안을 만들었고 로컬 콘텐츠 표시·정적/메뉴 검사를 통과했다. 실제 도메인 배포와 모바일 화면별 시각 검증은 아직 없다. 자세한 내용은 [구현 기록](website-implementation.md) 참고.

## 사용자 확정

- 브랜드 **Studio KWONYC / 스튜디오 KWONYC**, 기존 아이디 KWONYC 기반.
- 메인에 게임·개발 프로젝트·이력을 담는다.
- 홈페이지는 **Oracle VM에서 운영**한다. 다른 호스팅 전환은 채택하지 않았다.
- 도메인 **studiokwonyc.com**, 가비아 구매 완료.
- 심플하고 깔끔한 **모바일·태블릿·데스크톱 반응형** 디자인.
- STUDIO 위 / KWONYC 아래 로고 수용. 흰색·Illustrator 편집용 원본 요청.
- [Studio_KwonyC](https://github.com/kjk0189-boop/Studio_KwonyC)에 홈페이지·로고·위키를 함께 관리.
- 광고는 추후 검토이며 아직 도입하지 않았다.

## 확인된 운영

| 항목 | 상태와 근거 |
|---|---|
| 리전 | Osaka / KIX / ap-osaka-1 — 사용자 선택·캡처 |
| VM | kwonyc-web-01 생성 요청과 이후 SSH 로그인 |
| OS | Ubuntu 22.04.5 LTS / x86_64 — SSH 출력 |
| 자원 | 총 RAM 956Mi, 당시 루트 여유 42G — 명령 출력 |
| 네트워크 | kwonyc-vcn과 공개 서브넷 — 생성·Review |
| Caddy | active·로컬 HTTP 200 — 명령 출력 |
| 외부 접근 | 웹 포트 허용·규칙 저장 후 HTTP 성공 — 사용자 보고 |
| DNS | 루트 A·www CNAME이 서버 IP로 연결 — 사용자 조회 |
| HTTPS | 루트·www 양쪽 표시 성공 — 사용자 보고 |
| 브랜드 홈페이지 | 로컬 초안 구현, 실제 도메인은 Caddy 기본 페이지·배포 전 |
| 하루 스도쿠 | 기존 GitHub Pages 배포 — 사용자 보고·게임 문서 |

정확한 최종 Shape, 홈 리전·무료 사용량·MFA, 예약 IP, SSH 소스 제한, 방화벽 재부팅 유지, 인증서 상세·개별 리디렉션은 별도 미검증이다. 과거 A1 2 OCPU/12GB 계획을 현재 사양으로 쓰지 않는다.

## 다음

초안 디자인·소개 문구 검토 → 공개 이력·프로젝트 정보 → 실제 화면별 검증 → Oracle VM 배포. 존재하지 않는 경력·작품을 만들지 않는다.

게임을 기존 Pages 링크로 연결하는 것은 제안이며 Oracle 이전은 미확정이다. 스도쿠 코드는 별도 게임 저장소에 남긴다. 이 저장소는 VM 전체 백업이나 전체 채팅 원문이 아니다.

# 1단계 따라하기 — Oracle 계정과 출시 준비

> 이전 단계별 안내 보관: 아래의 현재·대기·미확인 표현은 당시 기록입니다. 최신 상태는 [프로젝트 현황](project.md)과 [체크리스트](checklist.md)를 따릅니다.

작성·공식 자료 확인일: 2026-10-26

목표: **Oracle Cloud 콘솔에 접속하고 홈 리전·무료 한도를 확인한 뒤, 대표 게임과 도메인 후보를 정한다.** VM 생성은 2단계에서 한다.

전체 진행 상태는 [체크리스트](checklist.md)에 기록한다. 사용자는 앞선 답변의 ①·② 계정 준비 완료를 보고했다. 구체적인 리전·MFA·무료 한도는 아직 미확인이다.

## A. 준비물

- 본인이 접근할 수 있는 이메일과 휴대전화
- 가입 화면이 요구하는 본인 명의·사용 권한이 있는 결제 수단과 정확한 청구 정보
- 비밀번호 관리자와 MFA에 사용할 인증 수단
- 현재 제작 중인 게임의 엔진 이름 또는 프로젝트 폴더

결제 정보·비밀번호·인증 코드·복구 코드·SSH 개인 키는 채팅이나 이 위키에 넣지 않는다. 계정명은 외부 사이트 도메인과 별개이므로 도메인 구매 전에도 가입할 수 있다.

## B. 기존 계정이 있는 경우

1. [Oracle Cloud 콘솔](https://cloud.oracle.com/)을 연다.
2. 클라우드 계정명(테넌시 이름)을 입력하고 안내에 따라 로그인한다. 계정명을 모르면 기존 환영 메일을 먼저 찾는다.
3. 일반 Oracle 웹사이트 로그인 계정만 있는 것과 OCI 콘솔 사용이 가능한 것은 구분한다. 로그인 후 실제 OCI 홈이 보이는지 확인한다.
4. 오른쪽 위 리전 선택기에서 현재 선택 리전을 확인한다. 리전 관리 또는 테넌시 정보에서 **홈 리전** 표시도 확인한다. 선택된 리전과 홈 리전은 같다고 단정하지 않는다.
5. 계정 상태가 무료 체험·Always Free·유료 중 무엇인지 콘솔의 계정/청구 화면에서 확인한다.
6. 사용자 프로필·보안 화면의 안내에 따라 MFA 상태를 확인한다.
7. 아래 D로 이동한다. 기존 무료 계정이 있으면 새 무료 계정을 추가로 만들지 않는다.

화면 명칭은 언어와 콘솔 개편에 따라 달라질 수 있다. 로그인 오류는 표시 문구를 기록하고 공식 로그인 지원 경로로 확인한다.

## C. 계정이 없는 경우

1. [Oracle Cloud Free Tier](https://www.oracle.com/kr/cloud/free/)에서 무료 가입을 누르거나 [공식 가입 페이지](https://signup.oraclecloud.com/)를 연다.
2. 거주 국가, 이름, 이메일을 입력한다.
3. 이메일 인증을 완료한다. 가입 화면에서 요구하는 비밀번호와 클라우드 계정명을 설정한다.
4. 홈 리전을 신중히 선택한다. **가입 후 홈 리전은 변경할 수 없으며 Always Free VM은 홈 리전에서 생성해야 한다.**
5. 한국 이용자를 주 대상으로 하고 서울이 선택지에 있다면 서울을 우선 검토한다. 이는 지리적 근접성을 고려한 제안이며 VM 재고를 보장하지 않는다. 공식 무료 리소스 문서에는 A1의 춘천 예외가 명시되어 있어, 이번 A1 계획에서는 춘천 선택 전에 적격성을 반드시 확인한다. 서울이 없으면 서둘러 다른 지역을 고르기보다 표시되는 선택지를 정리하고 계획을 재검토한다.
6. 주소·전화번호와 결제 검증 등 화면에서 요구하는 절차를 완료한다. 결제 수단 확인 과정에서 임시 승인 보류가 발생할 수 있다.
7. 약관을 읽고 무료 계정 가입 요청을 제출한다. 개통 안내에 따라 OCI 콘솔에 로그인한다.
8. MFA 설정을 요구하면 완료하고 복구 수단은 본인이 안전하게 보관한다.

무료 체험 크레딧은 기간이 있는 혜택이며 Always Free와 다르다. 이번 목표는 Always Free 범위에서의 운영이다. 가입 과정에서 별도의 유료 전환을 진행할 필요는 없다. Oracle은 무료 계정을 1인당 하나로 제한하므로 실패 시 여러 무료 계정을 반복 생성하지 않는다.

가입 오류가 있으면 오류 문구와 발생 단계만 기록하고 [공식 FAQ](https://www.oracle.com/kr/cloud/free/faq/)의 가입·로그인 지원 경로를 이용한다. 카드 승인 사유나 계정 승인 여부는 이 안내서로 판정할 수 없다.

## D. 무료 한도 확인

### 리전 표시를 찾기 어려울 때

리전은 서버가 위치하는 지역이다. 실제 로그인한 OCI 관리 콘솔 상단에서 현재 리전이 표시된다. 공식 안내는 상단 위치를 설명하며 화면 크기·언어에 따라 배치가 다를 수 있으므로 오른쪽 위치만으로 찾지 않는다.

1. [Oracle Cloud 콘솔](https://cloud.oracle.com/)에서 로그인한 관리 화면인지 확인한다. 계정명·이메일·비밀번호 입력 화면이면 로그인을 먼저 마친다.
2. 상단 바에서 국가·도시 형태의 드롭다운을 찾는다. 예를 들어 `US East (Ashburn)`처럼 표시될 수 있다. 이 예시는 사용자 실제 리전을 뜻하지 않는다.
3. 홈 리전을 확실히 확인하려면 상단 프로필 메뉴 → `Tenancy: 계정명`의 테넌시 정보를 확인한다. 또는 리전 메뉴 → `Manage Regions`에서 홈 리전 표시를 확인한다.
4. 그래도 위치를 찾기 어려우면 계정명·이메일·식별자 등을 가린 화면 캡처로 현재 화면을 확인한 뒤 안내한다. 이 단계에서 리전 구독·리소스 생성은 하지 않는다.

출처: [현재 리전 표시](https://docs.oracle.com/en-us/iaas/Content/GSG/Concepts/working-with-regions.htm), [홈 리전 확인 FAQ](https://docs.oracle.com/en-us/iaas/Content/GSG/Reference/faq.htm), [리전 관리](https://docs.oracle.com/en-us/iaas/Content/Identity/Tasks/managingregions.htm).

### 한도 확인 순서

1. 콘솔 메뉴에서 `Governance & Administration` → `Limits, Quotas and Usage`를 찾는다. 한국어 UI에서는 거버넌스 및 관리, 제한·할당량·사용량처럼 표시될 수 있다.
2. 리전을 홈 리전으로 맞추고 서비스에서 `Compute`를 고른다.
3. `A1` 또는 `standard-a1` 관련 항목을 찾아 코어·메모리 한도와 사용량을 확인한다. 표시되지 않으면 필터·리전·권한을 점검하고 미확인으로 남긴다.
4. 현재 공식 문서상 Always Free A1의 전체 기준은 **2 OCPU·12GB**다. 기존 VM의 사용량도 합산해야 한다. 콘솔에서 보이는 서비스 한도 자체가 전부 무료라는 뜻은 아니다.
5. 기존 인스턴스 목록에서 실행 중·중지 상태와 무관하게 남아 있는 리소스를 확인한다. 정체를 모르는 리소스를 삭제하지 않는다.
6. VM 생성 재고는 실제 생성 시점에만 알 수 있다. 한도가 있어도 `out of host capacity`로 생성이 실패할 수 있다.

이 단계는 한도 확인까지다. 생성 버튼은 2단계에서 이미지·사양·디스크·네트워크를 검토한 뒤 사용한다.

## E. 브랜드와 대표 게임 정리

1. 사용할 닉네임이나 브랜드명과 도메인 후보 2~3개를 적는다.
2. [가비아](https://www.gabia.com/)에서 후보를 검색하고 등록 가능 여부와 표시된 등록·갱신 비용을 확인한다. 부가세·할인 기간을 포함한 최종 금액은 구매 화면에서 확인한다. 이 단계는 후보 조사이며 구매는 4단계다.
3. 첫 게임 하나를 고르고 개발 도구나 프로젝트 설정에서 엔진·버전을 확인한다.
4. 웹 내보내기/웹 빌드 지원 여부와 기존 빌드 결과물을 확인한다. 엔진별 정확한 빌드 방법은 엔진을 확인한 뒤 별도 안내서에 기록한다.
5. PC만 우선 지원할지, 모바일도 필요한지 적는다. 로그인·랭킹·실시간 대전 같은 서버 기능의 필요성도 적는다.

게임이 준비되지 않았으면 이름과 엔진만 먼저 기록해도 된다. Oracle 계정 준비와 병행할 수 있지만 게임 확인 완료로 체크하지 않는다.

## 공식 출처와 검증 범위

- [가입 절차](https://docs.oracle.com/en-us/iaas/Content/GSG/Tasks/signingup_topic-Sign_Up_for_Free_Oracle_Cloud_Promotion.htm): 계정 개설, 홈 리전 변경 불가, 결제 검증.
- [Free Tier FAQ](https://www.oracle.com/kr/cloud/free/faq/): 무료 계정 제한, 결제 수단, 가입 지원, 체험과 상시 무료 구분.
- [Always Free Resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm): A1 한도, 홈 리전, 춘천 예외, 재고 제약, 콘솔 한도 확인 위치.

공식 문서는 확인했지만 실제 사용자 계정·가입 화면·리전 선택지·한도·게임 프로젝트는 직접 확인하지 않았다. 메뉴가 다르거나 오류가 나면 해당 단계와 비밀 정보가 없는 표시 문구를 기준으로 안내를 갱신한다. 실행 코드는 생성하지 않았다.

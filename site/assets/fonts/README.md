# 홈페이지 글꼴

## 사용 범위

- 한글: Pretendard, 공식 한국어 subset 400·500·600·700.
- 영문·숫자: Poppins 400·500·600·700. fonts.css의 Latin unicode-range로 구분한다.
- 히어로 장식의 make it playful만 사용자 후속 요청에 따라 기존 Georgia 세리프·italic으로 복원했다. 해당 문구 이외 본문·제목·보조 문구는 산세리프를 사용한다.
- 승인된 로고는 아웃라인 자산으로 그대로 유지한다.

## 출처와 라이선스

- Pretendard 1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/static/woff2-subset
- Pretendard 원본은 사용자가 지정한 스도쿠 프로젝트에 이미 보관된 동일 파일을 복사했다. 저작권·전체 SIL OFL 1.1은 Pretendard-LICENSE.txt에 포함한다.
- Poppins: https://github.com/google/fonts/tree/main/ofl/poppins — 2026-10-28 원본 다운로드. 전체 SIL OFL 1.1은 Poppins-OFL.txt에 포함한다.
- 양쪽 모두 공식 라이선스를 확인했고 폰트 파일은 수정하지 않았다. 홈페이지에서 외부 폰트 CDN에 요청하지 않는다.
- 파일 크기·SHA-256과 기본 바이너리 헤더 검증 결과는 font-manifest.json에 기록한다. 파일 검사는 실제 브라우저에서의 폰트 로딩 확인과 구분한다.
